# Jogo 
## N8-KILL: Espaço morto
Você é um soldado da N8-KILL, um exército que quer dominar o universo.

## Controles Padrões
**Seta para cima/esquerda/baixo/direita** - Movimentar  
**Tecla Z** - Atirar Tiro primário  
**Tecla X** - Atirar Tiro Secundário  
**Tecla C** - Usar carta de poder  
**Tecla V** - Trocar carta de poder  

## Objetivo
Sobreviva o máximo possível de ondas de inimigos e ganhe o máximo possível de pontos.
